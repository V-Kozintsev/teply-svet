# Как участвовать

Будем рады сообщениям об ошибках, идеям для уровней и исправлениям. Крупную идею лучше сначала обсудить в issue; небольшое исправление можно сразу предложить через pull request.

Перед отправкой:

1. Опишите, что изменилось и как это проверить. Для заметных изменений интерфейса приложите снимки настольной и телефонной версий.
2. Запустите `npm run build` и `npm run check:quick`. Если меняли уровень, проверьте реальное прохождение и сохранение результата.
3. Для новых шрифтов, звуков и изображений укажите источник и лицензию. Используйте только материалы, которые можно распространять вместе с игрой.

Собственные правки принимаются под [MIT-лицензией проекта](LICENSE); авторство сохраняется в истории Git. Решение о включении правки в основную версию принимает сопровождающий проекта. Отдельное соглашение о передаче исключительных прав или DCO не требуется.
