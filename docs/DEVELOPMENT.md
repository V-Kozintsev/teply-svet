# Путеводитель по проекту

Этот документ помогает продолжить работу с текущего состояния. Источником истины остаются исходный код и тесты: правила и уровни могут меняться.

## Где что находится

| Часть игры                                | Исходники                                                                                                                |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Меню, карта глав и выбор уровня           | `src/`                                                                                                                   |
| Порядок уровней и отображаемые номера     | `src/levels.ts`                                                                                                          |
| Сохранения и постоянные ID уровней        | `src/progress.ts`                                                                                                        |
| Подсказки, предохранители и звёзды        | `src/hints.ts`                                                                                                           |
| Схемы уровней и игровые правила           | `resources/references/ui-review/glass-chapter-one.js`, `glass-underground.js`, `glass-late-boards.js`, `glass-energy.js` |
| Общая страница уровня, рисунки и обучение | `resources/references/ui-review/glass-level.template.html`, `glass-hatch-art.js`, `glass-onboarding.js`                  |
| Сборка страниц уровней                    | `resources/references/ui-review/build-glass.mjs`                                                                         |
| Учёт ресурсов и проверка публикации       | `resources/manifest.json`, `resources/production-files.json`, `scripts/`                                                 |

В первой главе **26 игровых уровней** с максимумом **54 звезды**. Их видимые номера задают порядок в меню, а постоянные ID служат адресами страниц и ключами сохранений. Например, бывший ID `35` выведен из игры, но его история остаётся в сохранении. Новый финальный уровень имеет ID `45`; результаты прежнего финала с ID `12` сохраняются. При перестановке или замене уровня не переиспользуйте ID и проверяйте переход на следующий уровень.

`public/levels/` и `glass-level.html` создаются сборкой. Меняйте исходники, затем запускайте `npm run level:build`; ручные правки созданных страниц исчезнут. Для выпуска собирайте `dist/` через `npm run build`.

## Важные правила игры

- Проверочный импульс проходит короткий доступный участок не быстрее чем за 1,8 секунды; на длинных участках скорость ограничена примерно пятью клетками в секунду. Новый импульс начинается после завершения предыдущего и небольшой паузы. Скорость финального запуска и таймер уровня от этого не меняются.
- Обрыв ограничивает оставшееся время **30% от начального таймера**: если осталось столько же или меньше, сохраняется текущий остаток без прибавки и дополнительного списания. Правило едино для всех уровней; прежние бонусы 5-го и 8-го уровней отменены. Короткая анимация обрыва приостанавливает таймер, после неё отсчёт продолжается. Возвращение в ту же попытку после обрыва также не пополняет меньший остаток. См. `glassOutageRemainingMs` в `glass-energy.js`.
- Крестовина проводит ток по двум изолированным каналам. Реле открывает боковые заслонки после первого прохода и удерживает их до прохождения второго канала; новая попытка сбрасывает заслонки.
- Парные подземные люки — неподвижные выходы. Поворачиваются окружающие трубы. В 22-м уровне появляется труба на салазках: она перемещается между двумя клетками, сохраняя направление.
- Когда подземных пар две, их крышки и ободки различаются цветом: сиреневым и зелёным. Оба люка одной пары имеют одинаковый цвет. Это впервые появляется на 21-м уровне, затем на 25-м и 26-м; одиночная пара сохраняет латунный цвет.
- Рычаг поворачивает две отмеченные трубы одновременно. Рукоятка и контур связанной трубы имеют одинаковый цвет: бирюзовый у первой пары, коралловый у второй; зависимая труба отдельно не поворачивается.
- Заряд, звёзды, предохранители и подсказки связаны с сохранённым профилем. Не сбрасывайте профиль ради проверки новой схемы; используйте отдельное хранилище браузера.

## Языки

Поддерживаются русский и английский. Приоритет: сохранённый ручной выбор → `environment.i18n.lang` SDK Яндекс Игр → язык браузера вне платформы. Для остальных языков используется английский. Выбор хранится отдельно в `teply-svet.language.v1`, не меняет профиль и не перезапускает уровень. Кнопка 🌐 в меню переключает RU/EN; в настройках меню и уровня есть список языков.

Общий словарь — `src/translations.ts`, перевод динамических фраз и интерфейса — `src/language.ts`. Русские исходные тексты остаются основой; добавляя сообщение, добавляйте его перевод. Перевод затрагивает текст и подписи доступности, а не игровые данные. Исходные строки запоминаются для обратного переключения; элементы с `data-i18n-skip` не переводятся. При смене языка пересчитывается положение открытых обучающих облачков. Сборка создаёт общий `public/game-language.js`; не редактируйте его вручную. Его актуальность проверяет `level:check`, а включение в поставку — перечень `runtime` в `resources/production-files.json`.

Проверяйте оба языка, живые счётчики, магазины, обучение, результаты и возврат из уровня в меню. Особое внимание — 320/390-пиксельным экранам и переключению без потери попытки. Английские тексты для карточки каталога находятся в `docs/STORE.en.md`. Когда игра будет создана в кабинете, добавьте английскую карточку и снимки английской версии, включите русскую и английскую локализации и проверьте автоопределение в черновике платформы.

## Звёзды и пополнение

Одна подсказка стоит **5 звёзд**, один предохранитель — **3 звезды**. За полностью просмотренное вознаграждаемое видео игрок получает **1 подсказку** в магазине подсказок или **3 звезды** в магазине звёзд. Незавершённый просмотр ничего не начисляет; повторное подтверждение той же награды не даёт второй выплаты. Доступность видео зависит от подключения рекламной платформы.

Сохраняются три стартовые подсказки, одна подарочная подсказка за каждые 20 новых заработанных звёзд после открытия инструмента, бесплатная подсказка раз в сутки при пустом запасе, ежедневные два предохранителя при нулевом запасе и восстановление одного предохранителя за 20 минут до пяти. Повторное прохождение приносит только разницу при улучшении результата. Новые цены применяются к будущим покупкам и наградам: накопленные ресурсы, прежние покупки и сохранённые подтверждения рекламы не пересчитываются.

## Как прорабатывать уровень

Уровни **11–15** описаны в `glass-middle-boards.js` на полностью заполненных полях **6×6**. Постоянные ID — `1`, `41`, `39`, `40`, `2`; награды сохраняют потолки 1/2/2/3/3 звезды, таймеры — 115/90/70/75/85 секунд. Полные маршруты занимают 30/32/34/34/36 шагов и требуют минимум 46/50/54/58/62 поворота. На 11-м остаётся обрыв с тремя поворотами для ремонта; 12–13 сочетают реле со звездой, 14 — две звезды и длинные обходы, 15 — две звезды и закреплённую трубу. У каждого поля единственный маршрут максимальной награды. На 14–15 даже самое короткое решение требует 38/40 действий; проверены собираемые тупики длиной более двадцати клеток от обоих концов.

Уровни 23–26 описаны в `glass-late-boards.js` на полях 6×6. Их постоянные ID — 10, 11, 12 и 45. Первый знакомит с дальним рычагом и подземным обходом; следующий добавляет салазки и второе реле; затем появляются два рычага и две подземные пары; финал объединяет эти приёмы с обрывом. Таймеры — 165, 195, 205 и 215 секунд; у 22-го уровня — 160 секунд.

Полные решения требуют 56, 61, 62 и 60 обычных действий. На 24-м после обрыва нужно восстановить рычаг, салазки и крестовину: минимум три действия, аварийный запас — не больше 58,5 секунды. После обрыва финала нужны ещё минимум 12 действий; верхний предел его аварийного запаса — 64,5 секунды. У каждого уровня есть единственный маршрут на три звезды и более короткие варианты на две. Начальная сборка усложняется до 25-го, а финал требует больше всего действий вместе с ремонтом; частичный результат позволяет продолжить игру. Это начальный баланс, который следует уточнять по времени реальных прохождений, доле повторных попыток и использованию подсказок.

Сложность должна расти за счёт честных развилок и дополнительных действий. Проверяйте маршрут **от трансформатора и от дома**: очевидное начало с любой стороны не должно сразу выдавать всю схему. Ложный путь должен быть правдоподобным, но полное решение и все предусмотренные звёзды — достижимыми. Сверяйте реальные повороты, прохождение реле, люков, обрыва и таймер, а не только рисунок готового маршрута.

Обучающие облачка пишите коротко, обычно не длиннее двух строк на телефоне. У механики должен быть понятный зрительный отклик: состояние заслонок, обрыв, сгорание предохранителя и выбор кнопок нельзя показывать только текстом. Для изменений интерфейса проверяйте настольный экран и телефон **390 × 844**; для сложного взаимодействия проходите уровень в браузере от начала до результата.

## Проверка изменений

```bash
npm ci
npm run build
npm run check:quick
```

Эти же проверки запускаются в GitHub Actions при отправке изменений и pull request. Для адресной отладки доступны `npm test`, `npm run level:check`, `npm run typecheck` и `npm run release:check`. Перед сдачей убедитесь, что сгенерированные страницы актуальны и в коммит попали только нужные файлы. Для проверки на телефоне используйте `npm run phone`; работающий сервер и публичный туннель не требуют перезапуска после обычной правки файлов.
