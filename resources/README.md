# Библиотека материалов

Здесь хранятся исходники и ориентиры. В браузерную сборку попадает только выбранное содержимое `public`, а не вся эта библиотека.

## Готовые наборы

Шесть исходных наборов графики и интерфейса Kenney сохранены распакованными. Их ZIP-копии удалены после сверки каждого файла по SHA-256. Внутри наборов сохранены лицензии, изображения, векторы, листы спрайтов и авторские превью. Рекламные ярлыки сайтов удалены. Позже добавлен отдельный Kenney Fonts для сравнения цифр в выборе уровней; источник и лицензия сохранены рядом со шрифтами.

| Папка в packs         | Назначение                                           | Источник                                                                                                                           |
| --------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `background-elements` | Дом, деревья, облака, луна; уже используются         | [Kenney Background Elements Remastered](https://kenney.nl/assets/background-elements-remastered)                                   |
| `industrial`          | Блок питания, индикаторы, фонари; уже используются   | [Kenney Industrial](https://kenney.nl/assets/platformer-pack-industrial)                                                           |
| `ui-adventure`        | Панели кнопок, рамка окон и заполнение загрузчика    | [Kenney UI Pack Adventure](https://kenney.nl/assets/ui-pack-adventure)                                                             |
| `ui-pack`             | Звуки, кнопки, крестик, звёзды, стрелки и цифры      | [Kenney UI Pack](https://kenney.nl/assets/ui-pack)                                                                                 |

Выбранные изображения в `public/assets` являются отдельными копиями, чтобы вся библиотека не попадала в загрузку. Это нужное разделение исходников и игровых файлов.

`packs/kenney-fonts` — готовые шрифты из [Kenney Fonts](https://kenney.nl/assets/kenney-fonts), CC0. Полный набор сохранён для сравнения и в загрузку игры не входит. Выбранный Kenney Future Narrow подключён отдельным файлом из исходного Font в UI Pack, вместе с готовыми звёздами и стрелками. Все пять новых ресурсов зарегистрированы в manifest.json.

## Ориентиры

Для искр используется готовый particleYellow_7 из Puzzle Pack 2. Папка packs/sci-fi-sounds содержит выбранный оригинал forceField_000 из [Kenney Sci-Fi Sounds](https://kenney.nl/assets/sci-fi-sounds), короткую приглушённую версию и лицензию CC0. Это выбранная часть нового набора, не весь архив. Подготовка описана в README рядом со звуком. В public добавлены только искра и готовый звук, всего 6 348 байт, с лицензиями.

- `references/early-concept/background.png` и `prompt.txt` — ранний рисованный вариант; ориентир настроения, не обещание точного воспроизведения.
- `references/menu-v1/desktop.png`, `phone.png` и `source.fragment.html` — первоначальный одобренный макет. Текущий интерфейс уже исправлен по отзывам и отличается от этих исторических примеров. HTML-фрагмент хранится для справки, а не для повторного запуска старой сборки.
- `references/ui-review` — сохранённые сравнения рамок, счётчиков уровней и цифр. Это исторические пробы; рабочая реализация находится в src. Пояснения — в README этой папки.

## Реестр

`manifest.json` — единственный редактируемый список ресурсов игры. Для каждого файла указаны исходник, лицензия, размер и контрольная сумма. После изменения реестра выполнить `npm run assets:sync`: размеры, контрольные суммы и `src/assets.ts` обновятся автоматически. Исходный файл должен совпадать с выбранной копией.

Музыка помечена `preload: false`: она входит в реестр и итоговую сборку, но не в начальную загрузку меню. Для изменённой записи `source` указывает на подготовленную версию в packs/music; неизменённый скачанный оригинал хранится рядом. Происхождение и обработка описаны в packs/music/README.md.

`npm run assets:check` проверяет соответствие реестра файлам, лицензиям и ссылкам в интерфейсе. Не добавлять вручную второй список загрузки. Запасные материалы держать здесь; `public/assets` содержит только используемые ресурсы.

Кнопки «В меню» и «К уровням»: готовый button_rectangle_depth_gradient из Yellow/Double в UI Pack. В public он называется dialog-action.png, размер 1 300 байт; отдельная рамка из UI Adventure для этих кнопок больше не применяется.
